# Java-audio-player
uses the built in audio functions to build a spotify replica inside the terminal.
To run within the terminal use javac GUI.java to compile program on computer and java GUI to run.
These commands should open a window that allows the user to control the music including adding, removing, playing, and stoping functionality.

If you cant find the audio files you are looking for it may be because this only supports .WAV and certain .AIFF files.
